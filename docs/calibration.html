Is the decision model calibrated?

The loop asks d1-3B one question: is the evidence enough? The model returns a probability, the loop trusts it in the high band and delegates in the low band. This page checks whether the probability means what it says.

The reliability curve

The curve is the whole argument for a calibration band. A decision model that says 0.9 and is right half the time is not a small model with a cheap opinion, it is a random number with a latency cost. A model that says 0.9 and is right 0.9 of the time can gate a loop.

The bands

The loop keeps a d1 answer in the high band, delegates a low confidence answer to LFM2.5, and treats the middle band as its own. This table shows what each band was worth on this set.

45 of the ten probability bins are empty. A gap in the curve is not a failure; it is the corpus saying that the questions are either clearly answerable or clearly not.

What correctness means here

Correct means the answer cites a document that holds the gold answer. That is a cheap automatic proxy, and it is not a faithfulness score. A sentence can be true and cite the wrong record, and a record can be right while the sentence around it is wrong. The recorded turns are checked by hand for exactly this reason.

The Brier score is the mean squared distance between the probability and the outcome. Lower is better. A model that always says 0.5 on a balanced set scores 0.25; this one scores 0.055.

Reproduce it

The input is the committed loop report:

pixi run eval -- --place raptor-reserve --modes --unknown \
  --output lab/demos/raptor-reserve/evals/modes.json
pixi run calibrate

The report keeps every per-question row, including the probability, the band, and the citations, so each number on this page can be checked against the raw file.
