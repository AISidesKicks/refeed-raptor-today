# Raptor Reserve Corpus Notice

The 100 documents in `corpus/` are original text written for the Refeed Raptor project. The island, the reserve, the staff, the counts, and the incidents are fictional. The bird species are real.

**License:** CC BY 4.0. You may share and adapt the corpus with attribution to the Refeed Raptor project.

The data and methods wing summarizes public research in original words and links to the sources. No third-party text is reproduced. The sources are:

- RAPTOR paper, arXiv 2401.18059
- SearchJev paper, arXiv 2610.05107
- EmbeddingGemma 2 model card, https://huggingface.co/google/embeddinggemma-2
- LFM2.5-8B-A1B model card, https://huggingface.co/LiquidAI/LFM2.5-8B-A1B
- d1-3B model card, https://huggingface.co/LiquidAI/d1-3B
- llama.cpp server documentation, https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md

The corpus is synthetic. It is not a real reserve's records, and it is not a benchmark. The eval questions test retrieval on this corpus only.

The code in `tools/` is part of the Refeed Raptor lab. See the repository for the code license.
